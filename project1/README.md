# Project 1: Elementary Logic Gates

## Overview

This project focuses on designing fundamental digital logic gates using the HDL provided in the Nand2Tetris course.

Starting from the primitive NAND gate, all other gates are constructed hierarchically, demonstrating how complex logic can emerge from simple building blocks.

## Implemented Chips

* Basic Gates: AND, OR, NOT, XOR
* Multiplexers: MUX, MUX4WAY16, MUX8WAY16
* Demultiplexers: DMUX, DMUX4WAY, DMUX8WAY
* Multi-bit Gates: AND16, OR16, NOT16

## Key Concepts Learned

* Functional completeness of NAND gates
* Hierarchical hardware design
* Bitwise vs multi-bit operations
* Data routing using multiplexers and demultiplexers

## Approach

Each chip was implemented using the provided HDL skeleton files, ensuring correct naming conventions and compatibility with the Hardware Simulator.

The designs were verified using the built-in test scripts.

## Outcome

Successfully implemented and tested all required logic gate components, forming the foundation for arithmetic and CPU design in later projects.

## Relevance to Digital Systems

These gates form the basis of all digital circuits.
In FPGA architectures, similar logic is implemented using LUTs and routing networks, making this project directly relevant to hardware design workflows.
