# Project 2: Boolean Arithmetic and ALU

## Overview

This project focuses on building arithmetic and logic components using HDL, culminating in the design of a 16-bit Arithmetic Logic Unit (ALU).

The ALU performs a variety of operations based on control signals, forming the computational core of a computer system.

## Implemented Chips

* HalfAdder
* FullAdder
* Add16
* Inc16
* ALU

## Key Concepts Learned

* Binary addition and carry propagation
* Multi-bit arithmetic operations
* Control signal driven computation
* Functional composition of complex circuits

## Approach

The design was developed incrementally:

1. Built basic adders (HalfAdder, FullAdder)
2. Extended to 16-bit addition (Add16)
3. Implemented increment logic (Inc16)
4. Integrated all components into the ALU

Each component was tested using the Hardware Simulator.

## Outcome

Successfully implemented a fully functional 16-bit ALU capable of performing arithmetic and logical operations.

## Relevance to Digital Systems

The ALU is a central component of any processor.
This project demonstrates how low-level arithmetic operations are constructed and controlled, which directly maps to hardware implementations in FPGA and processor design.
